## 1. 概念与目标

深夜靛青的纸底上，玩家提着一盏铜灯走「冠军路」。路上有四种野外区域、十二种由符纹化成的兽。把野生符兽打到虚弱，再投出纸符印收服；带着最多四只兽，依次挑战青盏关、赤砂台、霜岩阶、六道坛的四位守关人。全部击破后六枚符钉在坛心合成一盏灯，主线完成。

记忆点：**六属性首尾相扣的循环**。焰克风、风克岩、岩克潮、潮克光、光克影、影克焰；克制 ×1.5、被克 ×0.67。玩家需要记住自己与对手的“下一环”关系，而不是只有一条四段克制链。

单人主线目标约 45 分钟（估算 40–60 分钟，见 §4.4；需人工试玩确认）。

## 3. 六属性与状态

### 3.1 克制环

`焰 → 风 → 岩 → 潮 → 光 → 影 → 焰`

| 攻方 \ 守方 | 结果 |
|---|---|
| 攻方下标 i，守方下标 (i+1) mod 6 | ×1.5（克制） |
| 攻方下标 i，守方下标 (i−1) mod 6 | ×0.67（被克） |
| 同属性 | ×1.0 |
| 中间隔 2–3 环 | ×1.0 |

例：焰打风 ×1.5；风打焰 ×0.67；岩打潮 ×1.5；潮打岩 ×0.67；潮打光 ×1.5；影打焰 ×1.5；焰打影 ×0.67。

### 3.2 状态

| id | 中文 | 持续 | 效果 |
|---|---|---|---|
| burn | 灼烧 | 3 回合 | 回合结束失去 `maxHP/16`（至少 1） |
| slow | 潮缚 | 3 回合 | 速度 ×0.6 |
| accdown | 风蚀 | 3 回合 | 命中率 −0.20 |
| atkdown | 影蚀 | 3 回合 | 攻击 ×0.75 |
| stun | 麻痹 | 跳过下一次行动 | 内部按 2 层计，跳过行动时清除 |
| shield | 护盾 | 直到被打破 | 独立吸收池，上限为最大 HP 的 65% |

状态技能有条目命中率；伤害技能附带的异常另有触发概率，见 §4.1。重复施加同状态会刷新持续时间。

### 4.2 等级成长

对等级 `L`：

```
maxHP = round(baseHP × (1 + 0.085 × (L − 1)))
ATK   = round(baseATK × (1 + 0.055 × (L − 1)))
DEF   = round(baseDEF × (1 + 0.05  × (L − 1)))
SPD   = round(baseSPD × (1 + 0.045 × (L − 1)))
```

等级上限 40。升级时按新上限补足增加的那部分 HP，不超额。

### 4.3 伤害公式

```
damage = max(1, round( ( ((2L/5 + 2) × power × ATK / DEF) / 20 + L × 0.5 ) × E × V ))
```

- `L`：攻击方等级；`power`：技能威力；`ATK`：攻击方有效攻击（影蚀 ×0.75）；`DEF`：防守方防御。
- `E`：属性倍率 1.5 / 1.0 / 0.67。
- `V`：随机浮动 0.92–1.08。
- 会心：基础 7%，风翎斩/墨爪额外 +8%，伤害 ×1.5。
- 命中：`技能命中 + 风蚀修正`，夹在 0.25–1.0；未命中不造成伤害与状态。
- 护盾先吸收，再扣 HP；护盾不吸收状态/灼烧。

回合流程：双方各出一招 → 按有效速度降序结算（同速玩家先手）→ 回合结束状态结算 → 检查倒下 → 下一回合。换兽消耗本回合，敌方仍会行动；倒下强制换兽不消耗额外回合。

## 5. 捕捉

- 只能对野生符兽投印；守关人的符兽免疫捕捉。
- 每次投印消耗 1 枚符印；没有符印时指令被拒绝，不消耗回合。
- 投印消耗本回合；若捕获失败，对手会行动。
- 捕获率：

```
chance = clamp(catch
             × (1 − 0.55 × hpRatio)
             × (statused ? 1.2 : 1)
             × (1 + clamp(0.03 × (myLevel − foeLevel), −0.2, +0.2)),
             0.03, 0.95)
```

以 `catch` 0.22–0.36 的符兽为例：满血无状态约 10%–16%；5% 血量约 21%–35%；5% 血量且带状态约 26%–42%。捕捉成功后进入队伍（最多 4 只），队伍已满则收入符兽录的备用栏；图鉴按 species id 去重。

### 6.3 进度、分数与存档

- `score = bosses × 1000 + caught × 100 + maxPartyLevel × 10 + floor(gold / 10)`（整数）。
- `progress = round(bosses/4 × 60 + caught/12 × 25 + min(maxLevel,30)/30 × 15)`，0–100。
- localStorage（前缀 `gbt.`）：
  - `gbt.boss`：当前周目已击败守关人数 0–4；`gbt.bossMax`：历史最高击败数。
  - `gbt.best`：历史最高分；`gbt.caught`：已收录 id JSON。
  - `gbt.save`：当前旅程（队伍、备用栏、金币、符印、守关数、位置、图鉴）。
  - `gbt.mute`：静音状态。
- 标题显示最高进度与最高分；有存档时主按钮为「继续旅程」，并出现「新旅程」。autotest 会快照全部 `gbt.*` 键并在结束前还原。

## 8. 工程与站点桥接

- `js/game.js`：状态机、探索、回合结算、UI/渲染、输入、上报、G 钩子、autotest。
- `js/data.js`：属性、状态、12 兽、技能、区域、Boss、经济与纯数值函数。
- `js/art.js`：12 种兽与全部场景/道具的程序化绘制。
- `js/audio.js`：WebAudio 合成；`js/fx.js`：粒子/飘字/圆环（上限 420）。
- 固定步长 60Hz，`dt` clamp 0.1s，单帧最多 6 步；页面隐藏时清空 accumulator；DPR 上限 2；resize 重新计算逻辑 1280×720 画幅与 letterbox。
- `?autostart=1` 直接进入探索；`?scene=battle` 直接进入一场 4 人队伍的代表性战斗（用于封面/截图）。
- G 钩子：`G.step/upd/press/release/setNoAuto/setReportTarget/state`，以及 `setSeed/setGold/setSeals/setBosses/setParty/startWild/startBoss/forceWin/forceFail/forceCapture/tapAt/uiRects/storageSnapshot/restoreStorage` 等。G 内所有状态修改都走 setter；`state()` 返回纯快照。上报帧序：`ready → progress → event → gameOver/complete`。
- 站点上报：对 `reportTarget` 保留扁平帧；向 parent 使用兼容信封：
  - `progress → {kind:'progress', data:{...}}`
  - `event → {kind:'event', event, data:{...}}`
  - `gameOver → {kind:'gameOver', score, progress:{value}, data:{...}}`
  - `complete → {kind:'complete', score}`
  - `ready` 另发 `{source:'lightgame', type:'lightgame:ready', gameId, v:1}`
- 本地 `static/play68.js`、`static/play68bar.js` 提供 `goHome / clickMore / dp_share / play68_submitScore / handleGlobalShare`；无外网、无追踪。
