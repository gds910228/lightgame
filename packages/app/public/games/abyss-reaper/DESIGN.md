# Abyss Reaper（暗渊割草者）— 设计文档

> guizang-game-skill 方法论第三批 #4。类型：2D canvas 幸存者-like 割草 Roguelite。
> 代码结构对齐标杆 orchard-fusion（固定步长主循环 / G 钩子 / `?autotest=1` 套件 / 站点上报桥 /
> WebAudio 全合成音频 / 离屏预渲染精灵）。素材降级路线，无外网依赖，无 CDN。

## 0. 决策

| 决策点 | 选择 | 依据 |
|---|---|---|
| 画幅/世界 | 固定逻辑 960×560 横屏，等比缩放居中 letterbox | 世界=屏幕，怪潮从矩形边缘环形刷怪（规格），桌面/移动都可玩 |
| 敌人并发 | 上限 280（ENEMY_CAP），自然刷怪受帽；均匀空间哈希网格（52px 格）做分离与投射物命中查询 | 220+ 敌 60fps 硬指标；网格把分离力从 O(n²) 压到 O(n×k) |
| 敌人渲染 | 每种敌人预渲染离屏精灵（含 Boss/玩家/晶石/拾取物），drawImage 直绘；受击白闪=白色圆形叠加 | 规格要求"同类型敌人预渲染离屏精灵" |
| 时钟 | 双时钟：`gameT` 运行时钟（刷怪调度/胜利判定，noAuto 可冻结）+ `simT` 模拟时钟（战斗受击冷却） | noAuto 下 gameT 冻结不应冻结战斗冷却——踩坑后拆分（见 §6 实测结果） |
| 镰刃判定 | 刃环 + **内圈守护**（刃弧扫过中心区，贴脸敌人同样被绞割） | 踩坑：敌人抵达玩家中心后落在刃环内洞里永不再受击（见 §6） |
| 幽火弹 | 追踪弹近距减速 + 终末转向贴合 | 踩坑：转向半径(≈69px) > 命中半径(≈26px) 时弹体永久环绕目标（见 §6） |
| 升级三选一 | 满足条件的进化**必进**候选首位，其余从池中随机抽 2；池不足用 回复40HP/+30XP 兜底 | 规格要求"满足条件时升级选项出现进化"，且测试可确定触发 |
| 胜利条件 | `gameT ≥ 900s 且 Boss 已亡` → complete 帧 | 规格"撑过 15min 死神降临胜利"+ 测试要求"timeJump 到 15min+击杀 Boss" |
| 音频 | WebAudio 全合成；BGM 三态 calm/fight/boss；SFX 全员节流（防怪潮音爆） | 约定 §4；BGM 音量 ≈ SFX 1/4 |
| 上报 | ready → progress{score=击杀, progress=分钟}（每分钟节流）→ event{boss/evolve/bossKill} → gameOver / complete | 站点协议 |

- 起手默认持「镰刃环绕」Lv1（开局 10 秒内必有第一次击杀正反馈）。
- 所有主动武器 CD ×(1−冷却缩减)，新增武器初始 CD 0.2s（即时反馈）。
- 进化条件：武器 Lv8 + 联动被动 ≥3 级。

| 敌人 | HP | 速度 | 触伤 | 半径 | XP | 特性 |
|---|---|---|---|---|---|---|
| 爬行者 | 14 | 42 | 6 | 13 | 1 | 直追 |

| 终极死神 Boss | 2600 | 34 | 20 | 34 | 40+晶石环 | 600s 登场；5 波弹幕循环（环形弹幕×4 涡旋/螺旋/定向霰弹/带缺口环）+ 蓄力冲撞（0.7s 预警线→440px/s 冲刺反弹）；顶部血条 |

- 时间缩放：HP ×(1+0.35·t分钟)，伤害 ×(1+0.05·t分钟)。
- 刷怪密度（规格公式）：`rate(t) = 2.2 × (1 + 0.12 × t分钟)` 敌/秒 + 每 45s 怪潮爆发 `10+3·t分钟` 只。
- 类型权重随时间：爬行者 46 / 疾冲者 30 / 装甲壳 t>2min 后 18（前 4）/ 毒雾蛾 t>3.5min 后 14（前 2）。

### 1.4 经济与掉落

- XP 曲线：`need(lv) = floor(5 + (lv−1)×8 + (lv−1)^1.7 × 1.5)`（Lv1→5，Lv5→52，Lv10→约 172）。
- 晶石：小 1（绿）/ 大 2（青，装甲壳与精英环）/ 精英 10 / Boss 40+12×2；晶石上限 420，超出自动折算最旧一颗。
- 掉落：回血鸡腿 2.5%（+25 HP）；磁石 1.0%（全图吸取直到清空）；精英 40% 鸡腿。
- 玩家：HP 100，受击后 0.55s 无敌闪烁，接触伤害走无敌帧节流。
- best：`abr.best` = JSON `{time:最长存活秒, kills:最高击杀}` 双独立最大值。

## 2. 文件结构

```

                预渲染精灵（敌人/玩家/晶石/鸡腿/磁石）、逐敌 AI（追击/冲刺/游走远程）

                投射物（斧/圣弹/幽火追踪）、毒沼 tick、雷链跳跃、受击冷却 wcd、绘制
js/upgrades.js  4 被动定义、XP 曲线、三选一构筑（进化优先+洗池+兜底）、卡片文案
js/audio.js     SFX 18 种（全节流）+ calm/fight/boss 三态 16 步合成 BGM
js/ui.js        DOM 层：HUD(时间/击杀/等级/血条/XP条)、Boss 血条、升级三卡、横幅/toast、
                虚拟摇杆可视层、武器芯片栏、标题/结算、静音/暂停钮

                刷怪调度、Boss AI、宝石/掉落吸附、协议桥、G 钩子、?autotest=1 套件
```

## 3. G 调试钩子

- 通用：`G.step(n,dt)`（带渲染推进）/ `G.upd(n,dt)`（只跑逻辑）/ `G.press(...codes)` /
  `G.clearKeys()` / `G.setNoAuto(v)` / `G.setReportTarget(fn)` / `G.setScore(v)` / `G.setHp(v)` /
  `G.state()` 只读快照 / `G.fx()` 特效计数 / `G.err`。
- 玩法专属：`G.spawn(kind,x,y)`（crawler/dasher/shell/moth/elite/boss）· `G.levelUp()` ·
  `G.choose(0|1|2)` · `G.giveWeapon(name,lv?)` · `G.givePassive(name,lv?)` · `G.giveXp(n)` ·
  `G.giveDrop('gem'|'heal'|'magnet',x,y)` · `G.timeJump(sec)`（推进运行时钟并处理调度/胜利）·
  `G.smite('boss'|最近敌)` · `G.hurtPlayer(d)`（绕过无敌帧，保留护甲）· `G.setJoy(dx,dy)`。
- 状态直达（只读引用）：`G.enemies / G.gems / G.drops / G.audio / G.ui`。
- URL：`?autotest=1`（自测静音、AudioContext 保持无 ctx 直到显式 ensure、测完回标题、写 `window.__TEST`）。

## 4. 站点集成

- metadata.json：id=abyss-reaper，category "Action,Roguelite"，英文 description/controls。
- 上报帧序：`ready` → `progress{score=击杀, progress=分钟}`（分钟变更节流）→
  `event{tag:'boss'|'evolve'|'bossKill'}` → `gameOver{score,progress}`（死亡）或
  `complete{score,progress}`（胜利）。

## 6. 实测结果（2026-11-18，源码目录静态服务 :8611，Playwright 实载）

- **59/59 断言全过 ×3 连续运行**（DoD 要求 ×2，多跑一轮验证防 flaky）；每轮控制台零报错
  （AudioContext 无手势/GPU ReadPixels 属环境豁免，runner 已过滤且本轮未出现）、零外网请求。
- 截图存档 `.scratch/guizang3/abyss-reaper/`：shot-title（标题）、shot-play（游玩中：
  骨白玩家+双镰环绕+血红怪潮+HUD+引导语）、shot-levelup（升级三选一面板）、shot-after-test。
- 220 敌 600 帧逻辑耗时实测 ≈300-500ms（远低于 12000ms 断言预算），分离力+网格查询 O(n) 达标。

**开发中实测修掉的坑（均有探针取证）：**

1. **受击冷却依赖 gameT 被 noAuto 冻结**——同一武器对同一敌人永远只命中一次
   （`gameT-last < wcd` 永真）。拆分双时钟：`simT` 随每次 update 推进供战斗冷却，
   `gameT` 供刷怪调度/胜利判定。
2. **镰刃环内洞盲区**——敌人抵达玩家中心后落在 刃半径64−命中29=35px 内圈里，
   起手武器对贴脸敌彻底失效（探针：爬行者 hp 14→6 后 240 帧不变）。加"内圈守护"判定修复。
3. **幽火弹 overshoot 环绕**——转向半径(sp/turn≈69px) 大于命中半径(26px) 时弹体绕目标永久
   旋转。近距减速（`spd=min(spd, 110+dist×3.2)`）+ <40px 终末转向贴合修复。
4. **胜利判定竞态（flaky）**——战斗最后一帧拾取 XP 触发升级 → `pending=true` 残留 →
   `checkWin` 的 `!pending` 守卫拦截 complete。测试在 timeJump 前排干升级队列，并给 Boss 战
   测试段加护甲/定期回血消除精英随机伤害方差。
5. **精英断言按爬行者硬编码阈值**——精英种类随机（疾冲者/毒雾蛾 ×1.6 后半径 <20）。
   改为校验"相对基础值 ×8 / ×1.6"不变量。
6. **spawnBolt 未定义**——updateEnemy ctx 引用漏定义函数，启动即 ReferenceError，补齐。

**需人工试玩确认**：实际手感（移速/刷怪压力曲线）、进化视觉冲击力、Boss 五波弹幕难度、
移动端虚拟摇杆跟手度、BGM 三态切换听感。
