# Bridgewright 造桥匠 · 设计文档

- **id**: `bridgewright`
- **系列**: 灯匠夜游 · 第 3 铺
- **类型**: 2D Canvas 物理造桥解谜
- **画幅**: 逻辑分辨率 960 × 540，按窗口等比缩放；横屏为主，竖屏居中显示可玩画幅
- **技术**: 纯 vanilla ES modules，无第三方库、无 CDN、无图片/字体/音频请求。所有画面为 Canvas 程序化绘制，所有声音为 WebAudio 实时合成。

---

## 1. 核心设计

一句话：**在暮色峡谷上搭一座真正站得住的桥，让矿车开过去。**

玩家得到一张固定的节点蓝图、一个造桥预算、三名工匠（木梁、缆索、石柱）。点击节点 A → 节点 B 拉出构件；木梁是木桥面与双向拉压杆，缆索只能受拉、便宜而轻，石柱从谷底顶住桥面节点、价格昂贵。按下 Enter 后矿车从左岸驶向右岸，矿车的重量按位置分给脚下相邻的两个桥面节点；桥面逐段下沉，构件的应力从玉青绿经铜黄变为釉朱红。应力持续超限、桥面节点越界或矿车坠落即失败；矿车抵达右岸即通关。

设计约束：

1. **必须用木梁把左岸—全部桥面节点—右岸逐跨连通**，矿车才能行驶。缆索和石柱只提供结构支撑，不能替代桥面。
2. 每关预算均按“作者参考解成本 × 约 1.11–1.38”生成，参考解一定买得起；但第 8 关以后，只用木梁铺满桥面的“裸桥”在正常车重下会因应力或塌落失败，必须使用缆索/石柱。第 1–7 关是教学坡度，裸桥可过，但支撑能把应力与星级做得更好。
3. 场景外观：深夜靛青纸底、暖铜金、釉朱、玉青；黄昏峡谷、月亮、远山、雾、蓝图网格、木梁纹理、缆索悬链、石柱砌块、矿车头灯、粒子与屏震。
4. 无随机物理：粒子使用随机数，但不参与力学；相同操作会产生相同压测结果。

### 操作

| 输入 | 行为 |
|---|---|
| 点击 / 触屏点按节点 A，再点节点 B | 用当前材料连接 |
| 从 A 拖到 B | 直接连接 |
| 1 / 2 / 3 或底部材料卡 | 木梁 / 缆索 / 石柱 |
| 选中石柱后点一个桥面节点 | 自动落柱到谷底 |
| Z / 撤销按钮 | 撤销最后一条构件并全额退款 |
| R / 重置按钮 | 清空当前关并重开（预算复原） |
| Enter / 开始压测 | 检查桥面连通后开始矿车压测 |
| P / 暂停按钮 | 暂停/继续压测（冻结物理） |
| M / 右上“声”按钮 | 静音/开启声音，状态写入 localStorage |
| 结算三键 | 下一关 / 再来一次 / 回标题 |

## 2. 材料与力学数值

节点为阻尼弹簧质点：4 个子步 / 帧，即 240 Hz 积分；单节点质量 `0.62`，重力加速度 `980 px/s²`，全局速度阻尼 `0.997 / 子步`。
构件为沿轴线的弹簧 + 轴向阻尼，应力 `stress = |轴向力 F| / maxForce`。

| 材料 | 价格公式 | 弹簧刚度 k | 阻尼比 ζ | 工作载荷 maxForce | 力学规则 |
|---|---|---|---|---|---|
| 木梁 | `round(长度px × 2.4)` | 2650 | 0.58 | 20000 | 同时抗拉与抗压；同一对节点只能有一条任意构件 |
| 缆索 | `round(长度px × 1.05)` | 2250 | 0.52 | 16000 | 仅 `拉伸量 > 0` 时受力；压缩时力=0、显示松弛 |
| 石柱 | `round(58 + 柱高px × 6.2)` | 12500 | 0.85 | 50000 | 只能从非固定桥面节点落柱；底端固定于 `y=472`；每个节点最多一根；竖向支撑 |

- 两节点间距离超过 `650 px` 或小于 `30 px` 时拒绝建造。
- 石柱节点距谷底小于 48 px 时拒绝建造。
- 预算不足、重复构件、非法端点均拒绝，且不扣款。
- 撤销与清空均全额退款。

### 压测与失败

- 矿车质量与速度逐关不同（见关卡表）。矿车重量完整地分配到所在桥面跨的两个节点，权重按位置线性插值。
- 当前跨必须有木梁；若被测结构被剪断/断裂，矿车失去支撑，0.8 秒后判定“桥面断裂，矿车坠落”。
- 平滑显示应力超过 `1.00` 持续 `0.30 s`，或瞬时原始应力超过 `1.16`，构件断裂并判负。
- 任意自由节点 `y > 525`、`x < 12`、`x > 948` 判负；矿车 `y > 501` 判负。
- 矿车 `x` 超过右锚点右缘 26 px 判定通关。
- 应力颜色：`< 0.55` 玉青绿（safe）、`0.55–0.82` 铜黄（warn）、`≥ 0.82` 釉朱红（danger）。木梁有额外半透明应力染色，缆索与石柱裂痕同步高亮。

### 星级

| 星级 | 条件 |
|---|---|
| ★ | 矿车抵达右岸 |
| ★★ | 抵达 + 峰值应力 ≤ 0.95 + 用时 ≤ `par × 1.35` |
| ★★★ | 抵达 + 峰值应力 ≤ 0.74 + 剩余预算 ≥ 关卡预算 × 8% + 用时 ≤ `par` |

`par` 由关卡跨度与矿车速度推出（见关卡表）。所有作者参考解均可获得 3 星（实测），但需要额外支撑才能把峰值应力压到 0.74 以下的高难关是合理的技巧空间。

章节：

### G 钩子（`window.G` / `window.__G`）

`err, step, upd, press, setNoAuto, setReportTarget, state, setBudget, buildMember, startTest, setLevel, forceFail, forceWin, cutMember, memberInfo, nodeInfo, nodeScreen, setCarMass, setCarX, setMaterial, undo, resetLevel, clearBridge, toTitle, nextLevel, computeStars, levelConfigs, solution, buildSolution, storageSnapshot, restoreStorage, reports, clearReports` 等。

### 压测演出（趣味性）

所有演出均为**表现层**：不改物理步长、不改任何力学数值，压测结果与星级判定与旧版完全一致。

| 演出 | 触发 | 表现 |
|---|---|---|
| 断裂慢动作 | 构件 snap | 真实时间进料 ×0.32 持续 ~0.85s（物理子步长不变 → 轨迹确定性不受影响）+ 断口白热爆点 +「啪——断裂！」浮字 |
| 应力吱呀声 | maxStress > 0.62 | 音调/音量随应力升高，间隔随应力收紧（0.6s → 0.16s） |
| 险情浮字 | maxStress 首过 0.55 / 0.88 | 「木头在呻吟…」/「千钧一发！」各一次 |
| 车轮火花 | maxStress > 0.8 | 后轮持续迸火花 |
| 矿车个性 | 常驻 | 车夫颠簸、车尾钟摆灯笼随桥面俯仰摆动、失支撑时「!」惊呼 |
| 胜利演出 | 矿车抵达 | 彩纸飘落 + 矿车小弹跳 +「抵达！」浮字；峰值应力 ≥ 93% 时结算注明「千钧一发！」 |
| 失败演出 | failLevel | 矿车翻滚下坠 + 车夫摇晃 +「塌了…」浮字 + 短慢动作 |
| 建造反馈 | 建造 / 撤销 | 「-120 铜」/「退 +80 铜」浮字 |
| 星级弹入 | 结算面板 | ★ 依次缩放弹入（CSS animation） |
| 流星 | 每 13s 两颗 | 纯装饰，时间确定性 |
- 所有内部可变状态通过 `setXxx` / `buildMember` / `forceWin` 等函数修改；`state()` 只读快照。
- 粒子在 `tick` / `G.step` / `G.upd` 中均调用 `updateFX(dt)`。
- `?autotest=1` 默认静音、测完回标题；`?autostart=1&level=N` 会加载第 N 关、铺参考解并进入压测（用于截图）。
- `?level=N` 直接进入第 N 关施工。

### 站点上报与存档

上报帧：`ready`（载入）→ `progress`（开始压测）→ `complete` 或 `gameOver`。分数为整数：`totalStars × 100 + level`，progress 为当前关号，另附 stars/time/stress/reason 等字段。
localStorage 使用唯一前缀：

- `brw.best`：历史最佳总星数
- `brw.stars`：`{ "1":3, ... }` 每关最高星级
- `brw.unlocked`：最高解锁关号
- `brw.mute`：静音状态

测试会先保存这四项原值，结束后逐一还原（`G.storageSnapshot` / `G.restoreStorage`）。
