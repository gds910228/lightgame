# Western Showdown Trio（西部决斗三连）— 设计文档

> 铜铃酒馆 · 第 15 铺。类型：2D Canvas 同屏反应三连（Duel / Action / Reaction / Local Multiplayer）。
> 日期：2026-11-26。全部代码与美术原创：程序化西部酒馆场景、纸质/木刻角色、三场反应迷你游戏、AI 记录分布、WebAudio 全合成音效与循环配乐；零外部请求、零 CDN、零字体/图片素材。

## 0. 决策

| 决策点 | 选择 | 依据 |
|---|---|---|
| 画幅 | 逻辑 960 × 540，等比缩放居中，DPR 上限 2 | 桌面、横屏触控完整可见；640×360 封面无需裁切 |
| 赛制 | 三场迷你游戏各一回合，胜场多者夺冠；平局加赛一场拔枪 | 同时满足「三连」「每场一回合」「平局加赛」 |

## 1. 玩法与状态流

```
标题（单人对 AI 记录：慢枪 / 中枪 / 快枪，或本地双人）
  → 第 1 场 · 拔枪对决（3 秒准备 → 等待 1.10–3.20 秒 → 信号）
  → 第 2 场 · 抢色按压（20 秒）
  → 第 3 场 · 记忆对决（30 秒 / 提前清空）
  → 胜场多者夺冠；平局 → 加赛 · 拔枪对决（再平继续加赛）
  → 结算：玩家夺冠 = complete；落败 = gameOver
```

- **拔枪对决**：双方先进入等待，信号灯亮起前按键即「抢跑」并立即判负该场；信号后先拔枪者胜。信号前有 1.10–3.20 秒随机等待，信号后 4.0 秒超时。反应时间按帧计量（约 16.7ms 精度）。
- **抢色按压**：左右各有独立目标色名与四色按钮。按钮的「实际填充色」与「字面颜色名」故意错配（Stroop 干扰），且每轮洗牌；必须按下与目标色名同填充色的按钮。命中 +100 并加最高 80 的速度奖励，错按 −50 并锁定 0.55 秒。最高 8 连击有音高递进与浮字反馈。
- **记忆对决**：4×3 共 12 张西部酒馆牌（6 对）。双方在同一牌桌上同时翻开，各自维护「第一张」；第二张不成对即失误并 0.70 秒后翻回。成对即归该方，双方可同时抢配，无需轮流。牌面清空或 30 秒到即结算。
- **加赛**：三场后胜场相同，复用拔枪规则打一场「加赛」；加赛再平则继续加赛。
- **记忆点**：抢色连击音阶与速度奖励、拔枪毫秒差、记忆双方同时抢最后一对、平局加赛一枪定胜负。
- **暂停**：P / 右上角按钮，冻结倒计时、信号、记忆翻回与 AI 自动动作。**重开**：R。**静音**：M。**回标题**：Esc / 结算按钮。

## 3. AI 记录与三档参数

AI 不是实时对称对打：每档是一条**反应/得分记录分布**。单人模式时，玩家与同一段记录比结果：

- 拔枪：AI 在信号后按分布抽一个反应时间；小概率抢跑。AI 自动拔枪在 `setNoAuto(true)` 时冻结。
- 抢色：AI 记录由每档的反应时间分布、准确率与错按锁定生成一条事件时间线；分数按与玩家相同的计分公式累计，右侧面板显示 AI 记录分。
- 记忆：AI 记录由「思考时间 + 每对间隔」生成 30 秒内能配到的对数与失误数；右侧显示 AI 记录对数。AI 不实际占用玩家牌桌上的卡牌，玩家可以翻完 6 对，最终比较双方对数。

| 参数 | 慢枪 slow | 中枪 medium | 快枪 fast |
|---|---:|---:|---:|
| 拔枪反应中位数 | 392ms | 300ms | 262ms |
| 拔枪反应 σ（对数正态） | 0.21 | 0.18 | 0.16 |
| 拔枪抢跑率 | 5.5% | 3.5% | 2.0% |
| 抢色反应中位数 | 770ms | 635ms | 535ms |
| 抢色反应 σ | 0.18 | 0.17 | 0.16 |
| 抢色准确率 | 85.5% | 89.0% | 92.5% |
| 记忆思考时间 | 1.7s | 1.4s | 1.05s |
| 记忆每对间隔 | 6.6s | 5.1s | 4.6s |
| 记忆失误率/对 | 0.85 | 0.55 | 0.30 |

**确定性**：AI 记录由每局种子派生，同一局内可复现；基准函数 `runRecordBench(n, diff, seed)` 使用固定种子，可完全复现。三档按钮在标题页明确标注「慢枪 / 中枪 / 快枪」并附说明。

## 4. 200 次 AI 记录基准与难度分离

### 4.1 共同脚本化人类模型（HUMAN_MODEL）

基准不是真人样本，而是一个固定的人类模型；请把它理解为「中等熟练玩家的可复现替身」。

| 人类模型参数 | 值 |
|---|---:|
| 拔枪反应中位数 / σ | 318ms / 0.20 |
| 拔枪抢跑率 | 5.0% |
| 抢色反应中位数 / σ | 545ms / 0.18 |
| 抢色准确率 | 90.0% |
| 抢色思考 / 锁定 / 重置 | 0.38s / 0.50s / 0.35s |
| 记忆思考 / 每对间隔 / σ | 1.2s / 5.35s / 0.18 |
| 记忆失误率/对 | 0.50 |

每档模拟 200 场完整三连（含平局加赛），种子固定为 `0x57a7e001` + 场次。运行脚本：`.scratch/western-showdown-trio/bench-full.mjs`；游戏内可通过 `G.runRecordBench(n, diff)` 复算。

### 4.2 200 场结果

| 档位 | 玩家胜率 | 玩家负率 | 平均玩家小局胜 | 平均 AI 小局胜 | 拔枪胜率 | 抢色胜率 | 记忆胜率 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 慢枪 slow | **98.0%** | 2.0% | 2.65 | 0.35 | 72.0% | 98.0% | 95.0% |
| 中枪 medium | **58.0%** | 42.0% | 1.63 | 1.38 | 40.0% | 80.5% | 42.0% |
| 快枪 fast | **8.0%** | 92.0% | 0.63 | 2.37 | 22.5% | 34.0% | 6.5% |

| 相邻档位 | 胜率差 | 是否 ≥15pp |
|---|---:|---|
| 慢 → 中 | **40.0pp** | 是 |
| 中 → 快 | **50.0pp** | 是 |

补充观测量（200 场均值）：

| 档位 | 抢色均分（玩家 / AI） | 记忆均对（玩家 / AI） | 拔枪反应中位数（玩家 / AI） | 玩家小局胜场分布（0/1/2/3） |
|---|---:|---:|---:|---|
| 慢枪 | 2615 / 1671 | 4.83 / 3.73 | 319ms / 391ms | 0 / 4 / 62 / 134 |
| 中枪 | 2591 / 2233 | 4.81 / 5.08 | 318ms / 301ms | 12 / 72 / 95 / 21 |
| 快枪 | 2600 / 2832 | 4.74 / 5.71 | 319ms / 262ms | 93 / 91 / 13 / 3 |

### 4.3 为什么能明显分层

1. **拔枪**：AI 中位反应 391 → 301 → 262ms 对固定人类 319ms。慢枪在反应与抢跑率上双重落后（人类拔枪胜率 72%）；中枪几乎与人类同速（人类 40%）；快枪快约 57ms（人类仅 22.5%）。
2. **抢色**：AI 记录均分 1671 → 2233 → 2832，人类约 2600。慢枪的 770ms/85.5% 记录被人类 545ms/90% 压制到 98% 落败；中枪 635ms/89% 仍略慢，但人类胜率降到 80.5%；快枪 535ms/92.5% 反超，人类只赢 34%。
3. **记忆**：人类 30 秒约 4.8 对；AI 慢 3.73 对明显落后，中 5.08 对略超，快 5.71 对接近满盘（6 对），人类只剩 6.5% 胜率。
4. **三局两胜放大**：单场优势通过三场累计与平局加赛放大，最终得到 98% / 58% / 8%，相邻差 40pp 与 50pp，远高于 15pp 要求。

### 4.4 关于 40–60% AI 自对弈

**本作没有实现对称 AI-vs-AI 对打**，因此「AI 自对弈胜率 40–60%」不适用于 L3 的格式。L3 是「玩家挑战 AI 记录」：AI 是一组反应/得分分布，不存在两个 AI 对打。上表以 200 次完整对局（同一脚本化人类模型 vs 三档记录）给出可复现的难度分离统计；这是本作对应的平衡证据。

### 4.5 自动测试中的缩减基准

autotest 使用 `G.runRecordBench(60, diff)`（三档各 60 场）。实测：慢枪 97%、中枪 65%、快枪 12%，相邻间隔 32pp / 53pp；断言要求严格单调且两段间隔均 ≥15pp。

## 5. 计分、上报与记录

- **小局比分** = 玩家小局胜场 : 对手小局胜场；平场不计胜场。
- **上报 score** = `p1Wins × 100 + p2Wins`（整数）。
- **progress** = 已完成小局 / 3 × 100（整数，最多 100）。
- **帧序**：`ready`（载入）→ 每小局 `progress{score,progress,mini,winner}` → 玩家夺冠 `complete{score}` / 落败 `gameOver{score,progress}`。
- 父页面信封：progress → `{kind,data}`；event → `{kind,event,data}`；gameOver → `{kind,score,progress:{value},data}`；complete → `{kind,score}`；并发送 `{source:'lightgame',type:'lightgame:ready',gameId:'western-showdown-trio',v:1}`。
- `setReportTarget(fn)` 可在测试中捕获所有帧。
- **持久化**：`wst.bestScore`（最高上报分）、`wst.matchWins`（P1/玩家方胜场）、`wst.matchLosses`（P2/对手方胜场）、`wst.mute`（静音偏好）。autotest 结束恢复测试前内存值与 localStorage 原值。
- **桥接**：`window.parent.handleGlobalShare(score)`、`parent.location.href='/'`；别名 `goHome / clickMore / dp_share / show_share / play68_submitScore` 均存在。

## 9. 美术与音频

- **场景**：2× 离屏预渲染的深胡桃木酒馆：暖窗光、酒瓶架、通缉令、吊灯与铜铃、木地板透视、纸纤维与浮尘。
- **角色**：锈红 P1 与靛蓝 P2 纸刻枪手：宽檐帽、蒙面巾、披风条纹、枪套与拔枪姿势、阴影与呼吸浮动。
- **拔枪**：中央信号灯、紧张弧线、怀表指针（不泄露准确等待）、「拔枪！」辉光、毫秒反应牌。
- **抢色**：双面板目标色、2×2 四色按钮、错配字面（干扰）、按键角标、分数/连击/进度条、AI 记录分。
- **记忆**：12 张牌背铜星纹样；正面程序化绘制警长帽、马靴、警徽、骷髅、马蹄铁、威士忌；双方虚线光标、第一张选牌环、成对侧色描边与 P1/P2/AI 徽章。
- **反馈**：命中火花/冲击环、错按红闪与屏震、翻牌、成对浮字、庆祝纸屑、约 70ms hit-stop、呼吸式灯焰。
- **音频**：首次真实手势解锁；合成信号哨、枪声（噪声爆裂 + 低频）、抢跑蜂鸣、抢色拨弦音阶、翻牌/成对/错配、胜负、暂停、分享；BGM 六态（标题/拔枪/抢色/记忆/结算/终局），音量约为 SFX 的 1/3。

## 11. 已知问题与后续

1. **音频未试听**：headless 全程静音且不创建 AudioContext；音色与混音仅按参数设计，上线前建议人工听感微调。
2. **AI 为记录分布而非实时对称对手**：抢色/记忆的 AI 记录分带时间线动画，但结果以该局预生成记录为准；拔枪为分布抽样的自动拔枪。这符合 L3「AI 记录挑战」定位，但不是对称 AI 对打。
3. **基准是模型**：HUMAN_MODEL 为固定脚本化玩家，200 场数据可复现但不等于真人分布；三档难度仍需真人试玩确认。
4. **竖屏体验**：采用 16:9 居中画幅，竖屏可玩但画面较小；建议横屏。窄屏触控键已改为可 2×2 换行，避免溢出。
5. **本地键盘 ghosting**：廉价键盘同时按多键可能冲突；触屏可替代。
6. **记忆平局判定**：对数 → 失误 → 最后成对时间；全部相同则平场，由整场加赛解决。
7. **上报分较粗**：score 由小局胜场构成（100×胜场 + 对手胜场），不叠加抢色分数；抢色分数只用于该场胜负与界面展示。这是为了让不同小局的比分语义一致。
