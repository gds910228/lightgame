# Twin Tempo Arena（双生擂台）— 设计文档

> 灯匠夜游 · 第 14 铺。类型：2D Canvas 同屏本地双人竞技（Action / Fighting / Local Multiplayer）。
> 全部代码与美术原创：自写角色运动、攻击/格挡/冲刺、灯台计分与冲量推挤；程序化纸刻夜场、朱红/靛蓝角色、铜金浮台与玉青灯台；WebAudio 全合成音效与循环配乐。零外部请求、零 CDN、零字体/图片素材。

---

## 0. 决策

| 决策点 | 选择 | 依据 |
|---|---|---|
| 画幅 | 逻辑 960 × 540，等比缩放居中，DPR 上限 2 | 桌面与横屏触控完整可见；640×360 缩略图无需裁切 |
| 视角 | 2D 侧视浮台，x 为水平、z 为离台高度 | 跳跃/击退/推落边界都能在同一坐标系里表达 |
| 局制 | 固定三回合轮换：斗剑 → 抢点 → 推挤；胜场多者夺冠 | 每回合一分钟上下，节奏清楚，三种机制各出现一次 |
| 平局 | 三回合胜场相同 → 加时一回合推挤 | 满足「平局加时一回合」；加时再平则重赛加时 |
| 物理 | 加速度 + 指数摩擦 + 重力跳跃 + 质量式击退/冲刺冲量 | 同屏竞技需要可读的速度与真实推挤感，避免外部物理库 |
| AI | 三档参数化，AI 固定代打 P2 | 参数与实移都可被 autotest 断言；玩家始终使用 P1 键位 |
| 输入 | 键盘双人 + 触屏左右各一套 | 一台设备即可本地对战；P2 支持 Numpad0/1 与 J/L 双别名 |
| 音频 | 首次真实手势建 AudioContext；全合成 SFX + 六态 BGM | 符合自动播放策略与系列约定；autotest 不建 ctx |

## 1. 玩法与状态流

```
标题（选 AI 易/中/难 或本地双人）
  → 第 1 回合 · 斗剑（3 秒倒计时）
  → 第 2 回合 · 抢点（结算 2.15s 后自动换场）
  → 第 3 回合 · 推挤
  → 胜场多者夺冠；相同则「加时 · 推挤」一回合
  → 结算：P1 夺冠 = complete；P1 落败 = gameOver
```

- **斗剑**：攻击削减体力；体力归零或时间到体力较低者负。玉青护栏让双方不会跌台。格挡只吃 3 点削减伤害与更小击退。
- **抢点**：中央灯台区半径 76。独自站在灯台内以 24%/秒积攒灯焰；两人同时站入则「争灯」，双方进度冻结。先到 100% 或时间到进度高者胜。此回合同样有护栏。
- **推挤**：浮台边界开放，并从 255 半宽缩至 138；攻击与冲刺产生冲量，把对手撞出边界即胜；时间到则离台心更近者胜。
- **加时**：浮台更窄（190 → 112），30 秒，推挤规则；平局再加时。
- **暂停**：P / 右上角按钮；冻结物理、计时与倒计时。**重开**：R 或结算按钮。**静音**：M / 右上角按钮。
- **里程碑**：每个回合结束上报 `progress`；整局结束按 P1 是否夺冠上报 `complete` / `gameOver`。

## 2. 物理与核心数学

| 参数 | 数值 | 说明 |
|---|---:|---|
| 地面加速度 | 1550 px/s² | 跑速渐近上限 280 px/s |
| 地面指数摩擦 | 5.7 /s | 松手后快速停步 |
| 空中加速度 / 阻尼 | 820 / 2.2 | 保留空中微调 |
| 跳跃初速 / 重力 | 470 / 1300 px/s² | 最高约 85 px，滞空约 0.72 s |
| 普通攻击 | 距离 64、高度差 64、伤害 13、冷却 0.42s、动画 0.18s | 命中前方；背对或高差过大落空 |
| 格挡 | 削减伤害 3、击退 130（普通击退 370） | 需面向攻击者 |
| 冲刺 | 速度 790、持续 0.18s、冷却 0.95s、无敌 0.16s | 可用于穿过攻击与推挤 |
| 斗剑击退 | 370，垂直分量 128 | 受击硬直 0.28s |
| 推挤攻击击退 | 500 | 推挤回合更强调位移 |
| 冲刺冲量 | `(360 + 相对速度 × 0.5) × 格挡系数` | 真实动量式；格挡时 ×0.45 |
| 抢点区 | 半径 76，24%/s，满 100% | 双人同站 => 双方 0 增速 |
| 浮台边界 | 推挤回合 `|x − 480| > half` 即跌落；斗剑/抢点有护栏，撞边软反弹 | 三种回合共用浮台，但只有推挤拆掉护栏 |
| 浮台半宽 | 普通 300；推挤 255→138（24s）；加时 190→112（12s） | 推挤回合逐渐收窄 |
| 最大粒子 | 380（超出从最旧开始淘汰） | 命中/落地/灯焰/庆祝各有粒子 |

核心数学断言（autotest 中实际执行）：
1. 按住方向键后速度上升、位置前移；松开后指数摩擦使速度显著衰减（T3）。
2. 正面攻击造成精确 13 点伤害并产生 >250 的击退速度；格挡只造成 3 点，击退 < 普通击退的 60%；距离 340 时攻击落空（T4 / T4.1 / T4.2）。
3. 跳跃后 z > 0，约 0.9 秒后回到 z=0 且 onGround=true（T5）。
4. 独站灯台 1 秒增加约 24%；两人同站时进度完全不变（T6）。
5. 冲刺撞击的冲量 > 700，受击者 vx > 600（T7）。
6. 越出台缘后立即跌落并判负（仅推挤回合；测试使用推挤场）。

## 3. AI 三档数值表

| 难度 | 跑速 px/s | 加速度 | 反应间隔 s | 好斗度 | 格挡率 | 边缘意识 | 冲刺率 | 跳跃率 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 易 | 150 | 1050 | 0.34 | 0.42 | 0.25 | 0.35 | 0.16 | 0.03 |
| 中 | 225 | 1500 | 0.17 | 0.72 | 0.55 | 0.62 | 0.42 | 0.06 |
| 难 | 300 | 2200 | 0.06 | 0.95 | 0.85 | 0.92 | 0.82 | 0.10 |

- **斗剑**：靠近至 82 px 内出剑；对手起手时按格挡率防御；残血时可能后撤；靠近台缘时回中心。
- **抢点**：目标为灯台中心；若双方都在灯内则贴住玩家；近身按好斗度攻击。
- **推挤**：优先远离台缘；近身攻击；冲刺冷却好时按冲刺率以动量撞人；对手起手时格挡。
- 三档速度/反应/好斗/格挡率在 autotest 中严格单调（T9）；相同 42 帧内难档实际移动距离显著大于易档（T10）。

## 4. 计分、上报与记录

- **本局比分** = `p1Wins : p2Wins`（每回合胜者 +1，平局不加）。
- **上报 score** = `p1Wins × 100 + p2Wins`（整数，例如 2:1 → 201）；`progress` = 已完成回合 / 3 × 100（整数，加时结算为 100）。
- **帧序**：`ready`（载入）→ 每回合 `progress{score,progress,round,type,result}` → P1 夺冠 `complete{score}` / P1 落败 `gameOver{score,progress}`。
- 父页面兼容信封按 WAVE-BRIEF：progress → `{kind,data}`；event → `{kind,event,data}`；gameOver → `{kind,score,progress:{value},data}`；complete → `{kind,score}`；另发 `{source:'lightgame',type:'lightgame:ready',gameId,v:1}`。
- **记录**：`twa.bestWins`（单局最多胜场）、`twa.bestTime`（P1 夺冠最快用时，秒）、`twa.mute`（静音偏好）。autotest 结束恢复测试前的内存值与 localStorage。
- **桥接**：`window.parent.handleGlobalShare(score)`、`dp_share / show_share / clickMore / goHome / play68_submitScore` 均存在；`goHome` 回站点 `/`。

## 5. 操作

| 动作 | P1 | P2 |
|---|---|---|
| 左右移动 | A / D | ← / → |
| 跳跃 | W | ↑ |
| 攻击 | F | J 或 Numpad0 |
| 格挡（长按）/ 冲刺（移动中按下） | G | L 或 Numpad1 |

- 触屏：横屏左右各一套网格按键（◀ 跳 ▶ / 攻 防），支持多点触控并分别驱动 P1/P2。
- 全局：P 暂停、M 静音、R 重开。开局标题与结算均有中文说明。
- 触屏按钮在 `(pointer:coarse)` 或检测到 touch pointer 后显示；桌面隐藏以免遮挡。

## 10. 已知问题与后续

1. **音频未试听**：headless 测试全程静音且不创建 AudioContext；音色与音量仅按代码参数设计，上线前需人工听感微调。
2. **AI 手感需真人调参**：难档反应 0.06s、跑速 300，数值上明显更强；是否过于压制、格挡频率是否自然，需要人工对局。
3. **本地双人依赖键盘按键无冲突**：P1/P2 键位已避开常见冲突，但部分廉价键盘同时按多键可能 ghosting；触屏模式可替代。
4. **触控为横屏布局**：竖屏仍可玩但左右两组按键会占较多画面；已针对 ≤430px 缩到 41px 按键并采用两行网格。
