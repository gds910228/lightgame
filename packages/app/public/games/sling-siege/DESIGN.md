# Sling Siege（弹弓拆塔记）— 设计文档

> guizang-game-skill 方法论第三批 #6。类型：2D 弹弓物理破坏（Physics/Puzzle）。
> 结构完全对齐标杆 orchard-fusion：固定步长主循环 + G 调试钩子 + `?autotest=1` 套件
> （MessageChannel nap）+ 站点上报桥 + WebAudio 全合成音频。代码全部原创
> （自写 AABB 刚体物理解算器 + canvas 程序化贴图），素材降级路线，无外网依赖。

## 0. 决策

| 决策点 | 选择 | 依据 |
|---|---|---|
| 物理 | 自写 AABB 刚体：半隐式欧拉 + 最小平移轴分离 + 单次冲量 + 3 迭代 | 块不旋转（符合"AABB 块"规格），避免引入 matter-js |
| 防抖 | 接地重力豁免（被支撑体不积 vy）+ 低速休眠（\|v\|<16 持续 0.22s）| 沿用 orchard-fusion 接地豁免思路；休眠块经 supportOn 级联唤醒 |
| 画幅 | 横屏逻辑 1280×720，等比缩放居中 | 弹弓→右塔的水平构图；桌面 letterbox、手机横竖均可 |
| 手感 | hit-stop（击杀 60ms/爆炸 85ms/碎石 50ms）+ 屏震（上限 9px）+ 碎裂粒子 + 击杀弹飞金星 | skill 手感三件套 |
| 经济 | 纯关卡推进，星数解锁章节（二/三章需 9/18★），无内购 | 规格指定 |
| 上报 | ready → progress{score, 关卡序/24}（3s 节流）→ event{clear} → gameOver（弹尽敌存）/ complete（通关 24 关）| 站点协议 |
| best | `sls.best` = JSON {levels: {关: {s:星, sc:分}}}，总星数由每关星数推导 | 规格要求"总星数+每关最高分" |

## 1. 玩法与数值

- **弹弓**：任意处按住拖拽（拉的方向反发射），拖距 110px=满力（MAXV=1200），<20px 取消；虚线轨迹预测 12 点（纯弹道）。
- **抛射物 3 种**（键 1/2/3 或点击弹药条切换）：
  - 石球 ball：质量 1.0，弹跳翻滚，命中伤害 = 冲击速度×质量×0.10；
  - 炸药 tnt：命中任意块/地/敌人或引信 1.2s 爆炸，半径 150px 伤害 170×(1-d/r)^0.8 衰减 + 冲击波推块，击杀半径 127px，引信内被冲击波波及则**链爆**（链爆半径 260px）；
  - 三连珠 tri：一次发射 ±7° 三向分散，单珠质量 0.4，碎裂即消失。
- **材质**（强度/密度/演出）：木 hp55 密度 1.0 易裂；石 hp130 密度 2.2 微损；玻璃 hp16 密度 0.6 华丽碎裂。伤害超强度→碎裂成 2-4 碎片（小 AABB，寿命 2.5s，出界或到寿消失）。块-块/落地碰撞按 (vn-140)×对方质量×0.02 结算碎裂伤害。
- **敌人**：小 1hp/中 2hp/大 3hp（分值 100/200/300），站块随支撑块位移，被抛射物直击 -1hp 并击退滑行；**坠落 >2m(100px) 落地 / 被动块压中(重叠>8px 且 块速>130 或陷入过半) / 冲击波 / 出界** → 即死 + 金星粒子 + 弹飞残影。守卫不主动移动。
- **判定**：全灭敌人→过关；弹尽且敌存且世界平静 2s→判负。星级 = 用弹 ≤par 得 3★ / +1 得 2★ / 其余 1★；剩余弹药每发 +100 分。
- **章节**：第一章 1-8 始终开放；第二章需总星 ≥9；第三章需 ≥18；章内逐关需通关前一关。

**实测结果**：2026-11-18 Playwright 实载（源码目录 `python -m http.server 8613` 独占端口）**41/41 断言全过连续 4 轮**（含 --shot 轮），控制台零报错（AudioContext 无手势 / GPU ReadPixels 属环境豁免，未出现），零外网请求（request 列表仅 localhost:8613 相对路径）。截图 5 张（标题/选关/瞄准轨迹/关卡中/测试后）+ 机关关抽检 3 张（L16/L17/L19）存 `.scratch/guizang3/sling-siege/`。

开发中实测修掉的坑：
1. **地面接触带导致永久悬停**：clamp 条件带 0.6px 容差时，回弹残留 vy=-19 的球每帧被 clamp 拉回且 grounded 恒真→重力永不恢复、速度恒 19>休眠阈值→永不休眠，弹尽判负永不触发。修复：穿透 clamp 与接触 grounded 判定拆成两个条件（仅真穿透才 clamp），并把休眠改为"纯低速计时"不依赖 grounded 翻转。
2. **摩擦过弱滚球不休眠**：地面摩擦 0.94→0.88，滚动球 45 帧内降速入阈值。
3. **solveShot 陡 lob 陷阱**：先功率后角度的扫描先命中 75° 高抛（1.9s 才落地），且 32px 容差大于实际 AABB 相交盒导致"解算说命中、实弹擦顶而过"。修复：角度升序外层+功率降序内层（优先平快弹道），默认容差收紧到 26px。
4. **章节索引错位**：断言里 `chapterUnlocked(2)` 实为第三章（0 基索引），修正断言语义。
5. **恰 100px 坠落幸存**：L1 初版木柱高恰 100px，敌坠落 100px 不满足 `>100` 幸存——改用直击解为主解并保持 2m 阈值与规格一致。
6. **碎片断言时机**：碎裂粒子 2.5s 寿命跨多个测试段，断言移到击碎后立即检查。
