# Deep Catch Saga（深海垂钓记）— 设计文档

> guizang-game-skill 方法论第三批 #5。类型：休闲钓鱼 + 收集养成（2D canvas）。
> 代码结构对齐标杆 orchard-fusion（固定步长主循环 / window.G 调试钩子 / ?autotest=1 套件 /
> 站点上报桥 / WebAudio 全合成音频）。素材全程序化（鱼形/场景/音效零外部资源），无外网依赖。

## 0. 决策

| 决策点 | 选择 | 依据 |
|---|---|---|
| 类型 | 三段式钓鱼循环 + 图鉴收集 + 金币升级 | 站内无同类；休闲无失败，收集驱动复玩 |
| 画幅 | 竖屏逻辑 540×960，等比缩放居中；世界坐标海面 y=260、6px/m、总深 360m | 竖持下潜沉浸感最好；桌面 letterbox |
| 三段循环 | 蓄力抛竿（摆针停中区）→ 下沉引导（左右避障）→ 拉杆博弈（张力 QTE） | 规格①②③逐条对应 |
| 深度=稀有度 | 咬钩鱼池严格取当前层 7 鱼，权重表随"稀有运气"升级右移 | 保证"浅层不出深渊鱼"可测 |
| 传奇鱼 | 每层 1 条（q6），金色王冠标记，拉杆节奏快-慢交替（0.42s/0.78s 挣扎交替） | 记忆点机制 |
| 失败设计 | 无 gameOver；断线（张力 3 次爆条）/碰礁只损失本次渔获并上报 event | 休闲定位 |
| 持久化 | `dcs.save`（金币/升级/图鉴/里程碑）+ `dcs.best`（最高单鱼分+收集度%）+ `dcs.mute` | localStorage |

## 1. 玩法与数值

- **蓄力抛竿**：指针 0↔100 摆动（92/s）；`power = 1-|pos-50|/50`；深度上限 `cap = 15+power×345` → 停中区=360m（第 6 档），边缘=15m（第 1 档）。
- **下沉引导**：基础下沉 62m/s（+14/级 ×4 级）；横移 130px/s；**礁石**=收线收回；**水母**=眩晕 0.8s（期间沉速 ×0.45、不可操控）；磁力吸附每级 30px/s² 自动推离 80px 内障碍；随时可收杆（空格/S/按钮）。
- **咬钩**：入水后 3~7.5s 随机；鱼池=当前层 7 鱼，基础权重 [34,24,16,10,6.5,3.5,1.6]；稀有运气 L 级：普通 ×(1-0.07L)，优良/稀有/史诗/传说/神话/传奇 ×(1+0.12L/0.24L/0.38L/0.55L/0.8L/1.1L)。
- **拉杆博弈**：张力初始 26；按住收线仅平稳期有效（progress +16.5→10.5/s 随品质递减）；挣扎期按住 tension +46→95/s（×容错 1-0.08L）；松手 decay 24/s（挣扎）20/s（平稳），挣扎松手漂移 +2.5/s；tension≥100 爆条（+1 次，回落 38），**3 次=断线**；progress≥100=捕获。传奇鱼（q6）挣扎时长 0.42/0.78 快-慢交替、rise 95。
- **42 鱼 = 6 层 × 7 品质**：品质分 [12,30,70,160,380,900,2600]，卖价 [6,14,34,80,190,460,1200]；体重 = 层系数 [0.4,1.2,3.5,9,25,70]kg × 品质系数 [1,1.5,2.2,3.2,4.8,7,12] × (0.55~1.7)。
- **图鉴**：42 格（未收集=剪影+？？？）；收集度%=n/42；里程碑 10/25/50/75/100% → +200/500/1200/2500/6000 金币（一次性）。
- **升级**（4 项 ×3~4 级）：下沉速度 [120,260,480,800]、张力容错 [100,220,420,700]、稀有运气 [150,320,600,1000]、磁力吸附 [200,450,850]。
- **手感三件套**：爆条/捕获 hit-stop 70-80ms；屏震（上限随品质）；粒子（气泡/水花环/捕获星散/传奇金闪）；金币飞入 HUD 动画；咬钩浮漂抖动+提示音。
- **场景**：天空 180s 日夜循环（黎明-白昼-黄昏-夜晚调色板插值+日月星云）；水体 6 层色带（浅滩青→深渊墨黑）预渲染长条；上层体积光；鱼群背景游动装饰；右侧深度标尺（6 层色块+刻度+当前深度指针）。


## 4. 上报协议

`ready` → `progress{score, progress=收集度%}`（≥3s 节流，捕获时触发）→
`event{tag:'legendary', score}`（钓到传奇鱼）/ `event{tag:'snap'}`（断线脱钩）/
`event{tag:'milestone', pct, coins}`（图鉴里程碑）。休闲无失败，**不上报 gameOver**。
best 键 `dcs.best`；存档键 `dcs.save`；静音键 `dcs.mute`。
