# Prism Paths（光路迷阵）— 设计文档

> guizang-game-skill 方法论第三批 #8，激光折射解谜（Puzzle/Logic）。主线程自建（波次 B）。
> 2D canvas 光路追踪引擎（visited 集合防环 + 4000 步保险），30 关手工关卡**全部带解法数据、自测逐关验证可解**。

## 0. 决策

| 决策点 | 选择 | 依据 |
|---|---|---|
| 类型 | 激光折射解谜 | 站内无同类；纯逻辑零运气，长线留存 |
| 元件 | 镜(/\\) 棱镜(分光) 滤色镜 冰镜(一次折射) 挡板 墙 三色+紫晶目标 | 渐进复杂度，紫晶需双色 = 后期记忆点 |
| 关卡 | 30 关×3 章 + par 三星 + 集星解锁章节(12/24) | 手工设计 + 关卡内嵌解法供自测回归 |
| 判定 | 光束在目标即熄灭；滤色镜吸收异色；冰镜单次追踪内折射后消融、追踪结束复原 | 保证任意旋转序列下解算确定性 |

## 1. 玩法

- 点击可转元件（镜/棱镜）旋转 90°；棱镜 = 按当前朝向反射 + 直射一路为二。
- 滤色镜只放行同色；紫晶需两种不同色光同时抵达。
- 撤销(Z)/重置(R)/选关(章节门 12★/24★)；best=`prp.best` 总星，`prp.stars` 逐关。

## 2. 文件结构

```

```
