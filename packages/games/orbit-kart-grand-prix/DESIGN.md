# Orbit Kart Grand Prix · 星环卡丁大奖赛 — 设计文档

- 系列：灯匠夜游 · Guizang 精品系列第三期 · 第 1 铺
- 类型：3D 卡丁竞速 / 街机
- 技术：three.js r170（本地 vendor）+ 原生 ES modules + Canvas 程序化贴图 + WebAudio 全合成
- 入口：`index.html`；逻辑入口 `js/game.js`
- 无外部请求、无 CDN、无运行时网络依赖。

## 1. 核心体验

三条悬浮赛道，三圈定胜负。玩家在弯道用漂移把「星焰」蓄到两段，松开换取爆发加速；沿路问号箱提供冲刺、追踪弹、路障三种道具。三名 AI 使用橡皮筋速度平衡，最后一段保留反超空间。竞速赛比名次，计时赛独自追最快圈。

记忆点：**漂移双段蓄气**——蓄满一段是短喷，超过 1.4 秒进入二段长喷；松开时还有 hit-stop、屏幕震动、粒子和音效叠加。

## 5. 状态与持久化

- `localStorage['okg.best.v1']`：每条赛道的 `rank`（最佳名次）、`lap`（最快圈，秒）、`score`（最高积分），以及总完赛数、胜场数。
- `localStorage['okg.mute']`：静音偏好。
- 上报帧：`ready → progress（过线）→ event（道具/加速）→ complete / gameOver`；分数始终为整数。
- G 钩子：`step / upd / press / release / setNoAuto / setReportTarget / startRace / toTitle / setS / setSpeed / setCrossings / setRaceTime / setScore / setLateral / setAI / grantItem / useItem / forceFinish / forceDNF / state / visual / rubberFactor / trackSample / renderInfo`。
- 三条铁律：状态修改全部经 setter；道具/粒子/追踪弹均在 `tick → updateEffects` 内更新；autotest 第一行 `G.setNoAuto(true)`。

## 6. 渲染与音频

- 渲染：WebGLRenderer，`devicePixelRatio` 上限 2，ACES tone mapping，固定 1/60 逻辑步长，rAF accumulator。
- 每帧复用几何体与材质；星空用 Points，问号箱/光晕用共享 sprite 贴图；所有贴图 Canvas 生成。
- 音频：WebAudio 合成引擎（随速度调频的 saw+triangle）、漂移噪声、道具/过线/胜负 SFX，以及三状态合成 BGM（标题/比赛/结算）。首次手势后才创建 AudioContext，M 静音；autotest 全程静音。

## 8. 已知取舍

- 赛道是手工调参的闭合曲线而非可自由编辑的编辑器产物；视觉道具使用程序化几何，因此近看是低多边形风格。
- 竞速 AI 不做车辆间硬碰撞，只做轻微线路避让与道具互动，以避免夹车卡死。
- 计时赛不记录名次，只更新最快圈与最高分。
- 移动端采用自动油门 + 刹车/漂移分离，保证单手可玩。
