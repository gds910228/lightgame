## 1. 玩法

- **操作**：WASD 移动；J/左键 攻击（三段连击，第三段重击）；K/右键 格挡·弹反；Space 闪避（无敌帧，最高优先级）；**L 剑气斩**（飞行剑气弹，CD 5s）；**U 剑雨**（范围落剑 6 道、智能瞄准近处敌人，CD 14s）。
- **战斗循环**：弹反成功 → 反击窗口（脚下亮环）→ 处决技（高伤）。破势条满 → Boss 长硬直。
- **成长（v1.1）**：每清一波三选一强化（点击或 1/2/3），10 种可叠加：锋锐（伤害）、罡体（生命）、疾风（移速）、剑气弹（重击放出飞行剑气）、汲血（命中回血）、流影（闪避消耗/CD）、韧皮（减伤）、气海（体力）、听风（弹反/反击窗口）、崩山（重击伤害）。左下角显示已获强化层数。
- **敌人**：
  - walker（持刀小怪）：游走、轮流出招，二连斩带扇形预警特效。
  - caster（远程）：读条发射法球（可被挥剑砍碎），落地法阵 AoE。
  - boss 石祠守卫：三连砸 + 地面冲击波（不可格挡，必须闪避）；50% 血进入二阶段（提速 + 弹幕环 + 地裂直线预警）。
- **掉落**：击杀蹦出药瓶/灵珠，抛起落地出声，靠近弧线飞入血条（skill 掉落物规范）。
- **移动端**：左半屏浮动摇杆 + 右下 3 按钮（攻击/格挡/闪避）。

## 2. 技术架构（js/ 九模块）

```
input.js  键鼠输入（skill 原版移植）+ 触屏摇杆
assets.js canvas 程序化贴图/材质/几何
rig.js    关节人体装配 + 两骨 IK + 五拍招式关键帧（起手→蓄势→挥出→过冲→收）
fx.js     剑气弧面 shader / 冲击环 / 预警特效(条纹流动) / 火花 / 粒子环缓冲
audio.js  WebAudio 合成 SFX + 三态配乐交叉淡入(探索/战斗/Boss, 音量为 SFX 的 1/3)
ui.js     代码画 UI（斜切血条/延迟掉血/技能冷却/Boss 名/横幅）
actors.js Player 状态机(吸附/顿帧/无敌帧/输入缓冲) + 敌人 AI(同一时刻一个近战出手) + Boss
world.js  场景/灯/雾/灰烬粒子/镜头(窄缩放+焦点缰绳)/遮挡淡出
game.js   主循环(固定步长)/波次导演/G 调试钩子/自动测试/?参数
```

## 3. 自测钩子（skill "怎么自己验证"）

- `G.step(n)` 手动推进带渲染、`G.upd(n)` 只跑逻辑、`G.press(...codes)` 模拟按键、`G.shot()` 截图。
- URL 参数：`?auto` 跳过标题、`?stage=w1|w2|boss`、`?god`、`?autotest=1`（跑完整套件 → `window.__TEST`，默认静音，测完回标题）。
- 数值为准、截图为辅；改完必须在浏览器实载并看控制台。

## 8. 随机夜事件（v1.4）

每波开始按概率触发（普通 40% / 无尽 55%，Boss 波只出增益事件，同一事件不连续两波），横幅公布：

| 事件 | 效果 |
|---|---|
| 血 月 | 场景染红；敌人伤害 +25%，但击杀必掉回复 |
| 雾 隐 | 浓雾视野大减；敌人移速 -20% |
| 剑 灵 | 每秒周期落剑自动斩向最近敌人，持续 18 秒 |
| 灵 潮 | 移速 +12%、体力回复翻倍、闪避耗 -8，持续 25 秒（脚下金环标识） |
| 恩 赐 | 祭坛苏醒，站在光圈内每秒回复生命 |
| 异 客 | 金装宝箱怪逃窜不攻击，击杀掉大回复 + 随机强化赏赐 |

剑雨 CD 由 14s 降至 **9s**。

## 7. 技能扩展（v1.3）

- **L 剑气斩**：朝面朝方向放出飞行剑气弹（28 伤害 × 强化），CD 5s；独立于重击附带的剑气弹（后者仍自动触发）。
- **U 剑雨**：以玩家为中心半径 3.5m 落下 6 道飞剑（每道 12 伤害），**智能瞄准**：优先锁定范围内最多 4 名敌人位置，其余随机散布；CD 14s。
- 两者都可被三选一强化（气斩/剑雨条目），技能栏扩为 5 图标，触屏新增 气/雨 两键。
