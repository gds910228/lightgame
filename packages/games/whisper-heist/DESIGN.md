# 声息窃影 · Whisper Heist — 设计文档

- **系列**：灯匠夜游 · 第 4 铺
- **类型**：2D 顶视角潜行 / 偷窃
- **技术**：vanilla JS ES modules，零外部请求；Canvas 程序化美术；WebAudio 全合成
- **画布**：逻辑 960 × 540，等比自适应，DPR 上限 2
- **关卡**：3 章 × 4 铺 = 12 铺手工关卡
- **单局时限**：180 秒
- **目标**：避开守卫，偷走本铺全部密匣，抵达出口按 E 撤离

## 1. 核心循环与记忆点

1. 观察巡逻路线与视野锥，利用高墙 LOS 遮挡与矮掩体（蹲行穿过）。
2. 站立移动会持续发出脚步噪声（半径 82）；蹲行几乎无声（半径 28）。
3. 声饵（Space/1 或触屏「饵」）落地产生半径 220 的声纹，把守卫引向落点。
4. 按 E 偷取密匣：加分、顿帧、屏震、金色粒子。
5. 偷齐后去出口按 E 撤离。被发现会依次进入「察觉 → 搜索 → 追捕」，警戒满、被追上或 180 秒耗尽即失败。

记忆点是 **声音的双面性**：噪声既会暴露自己，也是唯一能主动操纵守卫站位的工具；密匣、出口与巡逻路线的组合让每铺都可「绕」或「调虎离山」。

## 3. 数值表

### 3.1 玩家与声音

| 项 | 数值 |
|---|---|
| 玩家半径 | 9 px |
| 站立速度 | 138 px/s |
| 蹲行速度 | 68 px/s |
| 站立脚步间隔 / 半径 | 0.34 s / 82 px |
| 蹲行脚步间隔 / 半径 | 0.60 s / 28 px |
| 蹲行察觉倍率 | ×0.34 |
| 暗区察觉倍率 | ×0.48（视野距离同时 ×0.62） |
| 声饵投掷速度 / 飞行时间 | 340 px/s / 0.66 s |
| 声饵落点声纹半径 | 220 px |
| 声饵冷却 / 每铺数量 | 0.65 s / 3–6 枚 |
| 移动碰撞 | 圆形 × AABB，分轴解算 |

### 3.2 守卫与视野

| 类型 | 行为 | 视野范围 | 半角 | 听觉倍率 | 移动速度 |
|---|---|---|---|---|---|
| 固定守卫 `fixed` | 原地固定朝向 | 150–220 px | 0.50–0.62 rad（全角约 57°–71°） | ×1.0 | 0（搜索 92 / 追捕 128） |
| 巡逻守卫 `patrol` | 沿路径转向，端点停顿 0.7 s | 165–180 px | 0.55 rad（63°） | ×1.0 | 50–62 px/s |
| 听觉守卫 `hearing` | 原地缓慢扫视，耳力更强 | 150–175 px | 0.60–0.65 rad（69°–74°） | ×1.5 | 0（搜索 92 / 追捕 128） |

通用：

| 项 | 数值 |
|---|---|
| 视野判定 | 距离 ≤ 视野 && 角度差 ≤ half && LOS 无遮挡 |
| LOS | 高墙与矮掩体都阻挡视线（Liang–Barsky 线段/矩形） |
| 近距离察觉倍率 | `clamp(1 - d/range × 0.65, 0.35, 1)` |
| 警戒增长 | 25 × 距离倍率 × 蹲行/暗区倍率（取最危险的一名守卫） |
| 警戒自然回落 | 6.5 /s |
| 察觉（一级） | 警戒 > 1，HUD 显示「察觉」 |
| 搜索（二级） | 警戒 ≥ 25，-30 分，附近守卫前往最后目击点 |
| 追捕（三级） | 警戒 ≥ 66，-60 分，守卫追击最后目击点 |
| 失败 | 警戒 ≥ 100 / 追捕或搜索守卫贴身（17 / 12 px）/ 180 s 超时 |
| 搜索停留 | 5.5 s；随后返回原位 |
| 噪声搜查 | 每次事件使单个守卫由平静转入搜索，-20 分并计入 `searches` |

### 3.3 分数

| 事件 | 分数 |
|---|---|
| 偷取密匣 | +120 + 20 × 关卡序号（第一铺 120，第十二铺 340） |
| 通关时间奖励 | 剩余整秒 × 2 |
| 无搜查潜行奖励 | 全程 `searches == 0` 时 +200 |
| 触发噪声搜查 | −20（每次事件） |
| 警戒升到搜索 | −30 |
| 警戒升到追捕 | −60 |
| 分数下限 | 0，所有分数为整数 |

`best` 记录的是单铺最高分；`whh.progress` 记录已得手铺数。二者均在通关时写 localStorage。标题页展示 best、`X/12` 与十二个进度点；关卡选择中 `i <= progress` 可进入，其余上锁。

### 3.4 站点上报

`ready`（载入）→ 偷匣时 `progress{score,progress}`（节流）→ `complete` / `gameOver{score,progress,level,reason}`。进度值统一为 0–100 百分比。桥接函数保留 `goHome` / `clickMore` / `dp_share`，分享优先调用 `window.parent.handleGlobalShare(score)`。

三章主题：纸灯回廊（教学）、铜锁深院（巡逻与暗区）、釉朱密库（听觉与多守卫）。每铺均有 `fixed`、`patrol`、`hearing` 至少两类，全游戏三类齐备。地图使用 8 px 网格几何审计确认起点、全部密匣与出口均可到达；其中第 1、4、11 铺的内部密匣必须蹲行穿过矮掩体（有意设计的第二条路线）。

## 5. 美术与音频

- **美术**：深夜靛青纸底（`#0d1130 → #1c1430`）、暖铜金（`#c8a15a` / `#ffd77a`）、釉朱（`#c94f4a`）、玉青（`#6fe0c8`）。地面有纸纹、茶渍、石缝；墙为双层手绘线描 + 铆钉；矮掩体用青色虚线并画「蹲下」双箭头；视野锥半透明扇形，警戒升高由玉青→金→朱红；声纹为同心圆扩散；暗区有「暗处」标注。偷匣/被发现带 70–100 ms hit-stop、屏震与粒子。
- **音频**：WebAudio 全合成。`calm`（62 BPM 稀疏五声琶音 + 低频铺底）、`alert`（86 BPM 脉冲）、`chase`（124 BPM 低音追击）；音乐增益约为 SFX 的 1/4。SFX 包含脚步、轻步、偷取、投掷、落地、警报、发现、被捉、胜利、失败、门、UI。首次用户手势后创建 AudioContext；M/按钮静音并写 `whh.mute`；autotest 全程静音。
- **性能**：固定步长 60 Hz，dt clamp；静态地面与墙体分两层离屏预渲染（2×）；声纹与粒子在 `frame` 的 `updateFx` 中衰减；DPR ≤ 2。

## 6. G 调试钩子

`window.G` / `window.__G` 暴露：

- `err`、`step(n,dt)`（带渲染）、`upd(n,dt)`（只跑逻辑）、`press(...codes)`、`release(...codes)`、`clearKeys()`
- `setNoAuto(v)`、`setReportTarget(fn)`、`state()`
- `setLevel(i)`、`restartLevel()`、`toTitle()`、`startFromProgress()`
- `teleport(x,y,crouch)`、`forceAlert(v)`、`forceWin()`、`forceFail(reason)`、`setRelics(n)`（n=剩余数）
- `setScore`、`addScore`、`setTime`、`setDecoys`、`setMuted`、`setBest`、`reloadBest`、`setTouchCrouch`
- `emitNoise(x,y,r,kind)`、`throwDecoy()`、`interact()`、`lastNoise()`
- `math`（`angleDiff / inCone / losClear / noiseStrength / segRect / circleRect / moveCircle`）、`levels`、`getLevel()`、`audio`、`ui`
- 状态变更只通过 `setXxx` 函数，G 上不放置访问器。

URL：`?autotest=1` 运行套件；`?autostart=1&level=1` 直接进入第 N 铺（1 基）；`?level` 单独使用无效果。

### 7.3 已知问题 / 注意

- 视野锥在墙体后由墙体图层直接覆盖，属于视觉遮挡；实际判定同样使用 LOS，但扇形边缘贴墙处可能有 1–2 px 视觉差。
- 守卫搜索使用直线寻路，复杂拐角处可能短暂贴墙；约 5.5 秒后自动返回原位，不会永久卡死。
- `best` 为单铺最高分，不是十二铺累计总分（进度单独存于 `whh.progress`）。
- `?autostart` 与 `?autotest` 同时出现时，测试流程优先并会覆盖初始关卡。
- 浏览器若禁用 localStorage，best/进度仅保存在内存，静音状态不持久。
