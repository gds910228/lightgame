# Starfall Bulwark（坠星壁垒）— 设计文档

> 按 guizang-game-skill（op7418，AGPL-3.0）方法论开发的第二款游戏。类型与《剑祠守夜》（斜俯 3D 动作）**不同**：3D 塔防（Strategy / Tower Defense）。素材走 skill 的"无生成工具降级路线"：程序化几何 + canvas 手绘贴图 + WebAudio 合成音效/配乐；代码全部原创。

## 0. 调研结论与决策

| 决策点 | 选择 | 依据 |
|---|---|---|
| 类型 | 3D 塔防（区别于上一款动作） | 用户要求"不同类型"；TD 的波次导演/经济/词缀/无尽缩放可直接复用已验证的方法论 |
| 视角 | 固定斜俯全景（iso），整张地图一屏可见 | skill："斜俯视角省工作量、画面易精致"；TD 需要全局视野 |
| 场景 | 暮色峡谷：虚空传送门 → 蜿蜒石径 → 星核水晶 | 与暗蓝祠堂形成色彩区分（暖橙暮色 + 青色晶光） |
| 素材 | 程序化降级路线（无 Tripo/即梦/Suno） | README 允许的 fallback；上一款已验证效果 |
| 技术 | three.js r170 本地 vendor（676KB），不用外网 CDN | pitfalls："不要依赖外网加载库" |
| 泛光 | 复用自写两通道 bloom（sRGB pow 修复） | 上一款实测可靠 |
| 输入 | 移植 skill `scripts/input.js` 核心（防丢松键 + F3）+ 射线拾取 | "项目一开始就用它" |
| 打包 | 站点多文件静态目录 | skill packaging.md：在线托管先出画面 |

## 1. 玩法

- **目标**：星核 20 点完整度；敌人抵达星核 -1（Boss -5）。守住 10 波解锁无尽坚守。
- **经济**：星尘（essence）。开局 130。击杀掉落、清波奖励 20+2×波号、提前召唤 +15。
- **建造**：路径旁 12 个石台（pads）。点石台 → 底部五选一建卡（或 1-5）。已建塔可点击升级（U）/出售（S，返还 70%）。
- **塔（5 种，各 3 级）**：

| 塔 | 造价 | 特性 |
|---|---|---|
| 弩箭塔 Ballista | 50 | 速射单体，全目标 |
| 霜牙尖塔 Frost Spire | 70 | 冰晶弹 + 减速 35/45/55% 1.5s |
| 连雷图腾 Storm Totem | 100 | 链电 2/3/4 跳 |
| 熔核迫炮 Magma Mortar | 110 | 抛射溅射 r2，**打不到飞行** |
| 星光棱镜 Star Prism | 150 | 持续光束高伤单体 |

- **敌人（6 种）**：爬晶兽（基础）/ 疾行虫（快）/ 岩甲兽（护甲=每击减免）/ 浮游晶母（**飞行走直线**，迫炮无效）/ 蚀晶巫祝（群体治疗）/ 裂地巨像（Boss：践踏使最近塔停机 3.5s）。
- **祝福（roguelite 三选一）**：第 3/6/9 波清空后抽卡，10 种带上限（锋鸣/磐晶/透镜/霜寒/导电/燃熔/聚星/潮汐/核心重塑/过载电容）。
- **随机波事件（40%，Boss 波不出，不连续重复）**：精华潮（击杀×2）/ 星陨（3 颗陨石砸路径）/ 迷雾（射程 -20% 该波）/ 超频（前 18s 射速 +45%）/ 虫潮（+30% 敌人）。
- **无尽**：每循环生命 ×(1+0.16c)，精英词缀（疾/坚/磐，12% 双词缀）概率随循环上升；最高波次纪录存 localStorage（`sfb.best`）。
- **操作**：鼠标点选 + Space 召唤/加速、F 变速、P 暂停、Esc 取消；移动端点按石台/卡片 + 右上变速/暂停按钮。

## 2. 技术架构（js/ 九模块）

```
input.js   skill input 核心（防丢松键/IME/F3）+ 射线点击 + 触屏按钮
assets.js  canvas 程序化贴图（地面/路径石/辉光/流光）+ 几何材质 + textTag
world.js   场景/灯/雾/峡谷地形/路径曲线/石台/星核/传送门/bloom/相机/射线
fx.js      弹道（弩矢/冰晶/迫击弹/光束/链电）+ 落点冲击/陨石/裂纹/余烬粒子
enemies.js 敌人定义 + 路径参数 t 行进 + 飞行直线 + 血条 + 词缀 + 巫祝治疗 + Boss 践踏
towers.js  塔定义 + 建/升/售 + 目标选择（路径最前优先）+ 各塔开火 + 停机态
audio.js   WebAudio 合成 SFX + 三态配乐交叉淡入（建造/战斗/Boss）
ui.js      代码画 UI（核心条/星尘/波次预告/建卡/塔面板/横幅/祝福抽卡/结算）
game.js    固定步长主循环/波次导演/经济/事件/祝福/G 调试钩子/自动测试/站点上报
```

## 3. 自测钩子（skill "怎么自己验证"）

- `G.step(n)` / `G.upd(n)` / `G.press(...)` / `G.spawn(kind, t)` / `G.place(slot, kind)` / `G.shot()`。

## 4.1 v1.0.1 交互修复（玩家反馈：只有一个位置能建塔、升级无反应不扣费）

| 问题 | 根因 | 修复 |
|---|---|---|
| 点 UI 按钮（升级/建卡）后选择被清空 | 全局 mousedown 把 UI 上的按下也当场景点击，下一帧射线穿过 DOM 命中空处 → deselect()；若该帧落在 mousedown 与 click 之间，upgradeSel/buildOn 拿到的选择已被清掉 → 无反应不扣费 | isScene(e) 守卫：只有目标为 canvas 的按下才进场景拾取 |
| 触屏本/误触后所有鼠标点击永久失效 | 任何 touch 事件把 touchMode 永久置真，mousedown 一律 return | 触摸回声抑制改为 1.2s 时间窗，之后鼠标恢复 |
| 触屏下石台完全无法选中 | 触屏没有合成 mousedown，Click 从不进队 | touch pointerdown 直接写 NDC + pressed.add('Click')（tap-to-select） |
| 建卡打开时后排石台点不到 | #cards 容器 pointer-events:auto 吞掉穿透点击 | 容器 none，仅 .card 子项 auto |
| iframe 折叠瞬间 resize 后拾取全灭不自愈 | size() 在 0×0 时刻把 camera.aspect 写成 0/0=NaN，投影矩阵 x 列污染 | size() 拒收 0/NaN 视口 + world.update 每帧自愈（含 isFinite 判断）+ HiDPI pixelRatio |
| 升级失败无提示 | 满级/未选中等失败静默 | toast 提示（已满级/星尘不足含金额） |

## 4.3 v1.1.0 深潮（玩家反馈：25关满配后挂机无敌、怪物无变化、技能没增加）

- **玩家主动技能（Q/E/R，战斗中施放，带冷却与技能栏 UI/触屏键）**：
  - Q 星陨术（30s）：三连陨石，落弹瞬间重索敌群最密聚类质心，各 100 伤害/半径 2.4；
  - E 冰封新星（45s）：冻结全场 2.5 秒 + 随后 40% 减速 5 秒；
  - R 过载脉冲（35s）：全塔射速 +45% 持续 10 秒。
- **无尽缩改复利**：生命 ×1.10^波（25关≈5.6×、35关≈16×、45关≈46×）×循环系数，移速成长上限放宽，护甲 floor(波/8) 随深度成长——满配塔不再自动碾压。
- **新行为词缀**（按循环解锁：循环2「裂」、3「盾」、4「潜」；词缀数 1→2→3，概率随循环升）：
  - 裂：死亡分裂两只 35% 生命幼体（不分裂再分裂）；
  - 盾：25% 最大生命吸收盾，脱战 4 秒全量再生（血条蓝色上条显示）；
  - 潜：每 5 秒潜地 1.2 秒（无敌+2.2 倍速，浮出特效），塔/溅射/链电全部跳过潜地者。
- **恶性事件**（波≥16 后入池，事件概率随循环 55%→80%）：磁暴（随机塔三次停机 4s）/ 晶蚀（本波敌甲 +3）/ 狂潮（本波敌速 +30%）。
- **巨像数量递增**：无尽 Boss 波每 2 循环 +1 头（25 关 2 头、35 关 3 头），血条显示 ×N。
- **工程修复**：星陨飞行中的陨石跨波误伤（endWave 时 fx.clear + 清空打击队列）；星陨改聚类质心瞄准（弯道弧长修正）。
