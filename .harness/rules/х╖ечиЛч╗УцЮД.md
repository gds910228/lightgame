# 工程结构

> SOP 阶段三 · Rules ① | 稳定约束,Agent 常驻上下文(L1) | 每条规则对应历史教训

## 1. Monorepo 布局

```
Lightgame/
├── packages/
│   ├── app/          # 主 React 应用(Vite + TS,唯一 npm workspace)
│   └── games/        # 游戏源(每游戏一目录,含 metadata.json)
├── scripts/          # 游戏管理自动化(CommonJS,根级)
├── .github/workflows/ # CI(validate-games + deploy)
├── .harness/         # Harness 资产(agents/rules/skills/changes/mcp)
├── wiki/             # 业务上下文知识库(L3 按需)
├── docs/             # ⚠️ 被 .gitignore 忽略,勿放需入库的文档
└── vercel.json       # ⚠️ 残留,GitHub Pages 部署时不生效(见 deploy-verify)
```

> **教训**:`.gitignore` 忽略 `/docs` 与 `.claude`。需入库的文档/资产只能放 `.harness/` 或 `wiki/`。

## 2. app/src 分层架构

| 层 | 路径 | 职责 | 约束 |
|---|---|---|---|
| UI 组件 | `components/` | 可复用展示组件 | 不直接调 service,通过 props/Context |
| 页面 | `pages/` | 路由级页面 | 编排组件 + 调 service |
| 状态 | `contexts/` | Context Provider | 仅放跨组件共享状态 |
| 服务 | `services/` | 数据/外部 API | gameService / emailService |
| 类型 | `types/` | TS 类型定义 | 全局共享类型集中此处 |
| 入口 | `App.tsx` / `main.tsx` | 根组件 + Provider 包裹 | — |

> **教训**:`GameDetailPage.tsx` 495 行偏大,信号是"做得太多";新增逻辑优先下沉到 service 或拆子组件,而非继续堆页面。

## 3. 游戏目录结构

```
packages/games/{game-id}/
├── metadata.json   # 单一真相源
├── index.html      # local 游戏必需;iframe 游戏由 sync 生成 wrapper
└── (游戏资源/封面/缩略图)
```

- **id 命名**:kebab-case;**新增游戏 id 必须与目录名一致**(教训:现状有 `snake/`→id `snake-classic` 不一致,不再新增此类)
- **local vs iframe**:`type` 字段或按 `iframe_url` 存在判定;iframe 仅 `https://1games.io/`
- **封面/缩略图**:优先 SVG,大图用 `optimize-games` 压缩

## 4. scripts 分层

| 脚本 | 用途 | 触发 |
|---|---|---|
| `validate-games.js` | schema + iframe 嵌入预检 | CI + 手动 |
| `sync-games.js` | 源 → public/games 同步 | build 前 / 手动 |
| `build-games-list.js` | 生成 games.json | build prebuild |
| `watch-games.js` | dev 时自动 sync | dev:watch |
| `lib/can-embed.js` | 嵌入校验库 | 被 validate 调用 |
| `schemas/metadata.schema.json` | 元数据 JSON Schema | 被 AJV 校验 |

> **教训**:根级 scripts 用 CommonJS(`require`);`packages/app/scripts/` 用 ES module。**勿混用**。

## 5. 文件放置规则

- 工具类/纯函数 → `services/` 或独立 util(勿散落组件内)
- 常量 → 顶层 `constants/`(若新增)或就近定义并导出
- TS 类型 → `types/index.ts`(当前仅 13 行,新增类型集中补此)
- 游戏静态资源 → `packages/games/{id}/` 内,不进 `app/public/`(由 sync 拷贝)
- 文档 → `wiki/`(需入库)或 `docs/`(不入库,仅本地)

## 6. 配置文件归属

| 配置 | 位置 | 约束 |
|---|---|---|
| Vite | `packages/app/vite.config.ts` | `manualChunks: undefined` 不可改(教训:ForwardRef 修 3 次) |
| TS | `packages/app/tsconfig.json` | 保持 strict + noUnusedLocals/Parameters |
| Tailwind | `packages/app/tailwind.config.js` | — |
| CSP/头 | `vercel.json`(GH Pages 不生效)/ GH Pages 头另配 | iframe 仅 1games.io |
| CI | `.github/workflows/` | Node 版本统一 20 |
